## 录题 / 组卷 / 打印（本轮，已交付）

用户原话：「录入题目和制作试卷交互能够更友好更方便，制作好的试卷支持预览，保存的试卷能够打印」。
选型：**浏览器打印**（不引依赖）/ **只做学生版**（带答题留白，不含答案）/
**组卷预览 + 逐题可换 + 按点设量** / **抽屉交互升级**。

### 后端：组卷拆两步（BE-P-09 / BE-P-10）
- `POST /api/papers/generate/preview` —— **只试抽不落库**。返回 `PaperGeneratePreviewVO`
  { questions, total, picks[{kpId,kpName,wanted,available,picked}] }。
  `picks` 让前端能诚实提示「想抽 10 题、题库只有 3 题」，而不是静默少给。
- `POST /api/papers/generate/commit` —— 按确认后的 `questionIds` 建卷 + 编排（一步完成，不用再调 questions/set）。
- `PaperGenerateDTO` 扩展：`kpCounts: [{kpId,count}]`（**按点设量，优先于 countPerKp**）、`maxTotal`（整卷上限）。
  `countPerKp` 保留为兼容字段。
- 新增 DTO/VO：`KpCountDTO`、`PaperGenerateCommitDTO`、`PaperGeneratePreviewVO`。
- 重构要点：`generate()` 原来把「建卷 + 抽题 + 插 link」揉在一起，现在抽出
  `normalizeCounts()`（补齐题量）、`selectPool()`（候选池 by kp+grade+difficulty，只取通用题 studentId is null）、
  `pickQuestionIds()`，`generate`/`generatePreview` 共用。**旧 `POST /generate` 端点保留**（行为等价）。
- commit 的两条错误路径：题号全空 → 400「组卷至少需要一道题」；题号全失效 → 400「所选题目均已失效，请重新组卷」。

### 前端：组卷两步向导（PaperListView.vue）
- 原「一键组卷」单弹窗 → **el-steps 两步**：① 选知识点·按点设量（每个勾选的知识点旁边一个 input-number，
  上限=该点题量）② 预览卷面·逐题替换。
- 预览步：顶部「换一批」（整卷重抽）/「返回调整」；每题右「换一题」/「去掉」；
  题量不足用 el-alert 列明 `要 N 题、仅 M 题`；底部「确认生成试卷」才落库。
- 「换一题」实现：以**该题所属知识点**为单位单独 preview（count = 已占用 + 已排除 + 1），
  在前端过滤掉「别处已用」与「本位置已排除」后取第一道，实现不重复的同点换题。
- `openPrint()` / `printPaper()`：`router.resolve({name:'PaperPrint',params:{id}})` + `window.open`，
  新标签打开，不丢列表筛选状态。列表行、详情抽屉、预览弹窗三处都有打印入口。

### 前端：打印视图（PaperPrintView.vue，新建）
- 路由 `/print/paper/:id` **挂在 AdminLayout 之外**（顶层路由），无侧栏无导航，Ctrl+P 直接出整页。
- 屏幕态渲染成一张 210mm 竖版 A4（box-shadow 拟纸），打印态 `@media print` 去掉底色/阴影/留白，
  `@page { size: A4 portrait; margin: 16mm 14mm }`。
- **按题型分大题**：顺序由 `QTYPE_ORDER` 常量决定（选择/填空/判断/阅读/古诗文/写作/其他），
  大题标题「一、选择题（共 N 小题）」；`.big-q`/`.q` 加 `break-inside: avoid` 防分页切断。
- **学生版**：只输出题干+选项+作答留白，**不渲染 answer/analysis**（后端返回里有，前端有意不画）。
  留白按题型区分：选择/填空/判断 1 行、阅读/古诗文 3 行、写作给 200px 空白框。
