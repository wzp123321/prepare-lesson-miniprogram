## 1. 项目背景与目标

### 1.1 背景
独立教师每月需为多个学生排课（每天哪个时间段给哪个学生上课），并频繁遇到：
- 学生请假 / 老师本人有事请假；
- 请假课程需要**顺延**到后续某天补上；
- 目前用**纸质表格**记录，难以追踪「哪节课还没补」「欠了学生几节」「当月收入多少」。

纸质记录的最大痛点是**顺延课程容易漏补、无法自动统计**。

### 1.2 目标
开发一套排课管理系统，实现：
1. **排课录入**：当月课表可视化编排（拖拽学生入格）。
2. **状态管理**：每节课可标记 正常上课 / 顺延（带原因） / 已补 / 作废。
3. **补课闭环**：顺延的课程进入「待补课」，安排进后续月份课程后关闭。
4. **数据总览**：按月查询上课情况、未上课明细及原因、月度收入统计。
5. **实时可见**：进门即看当天课程与待补提醒。

### 1.3 范围边界（已确认）
- 只上 **语文**：课程科目固定，不提供选科。
- 暂**不登录**（单人使用）。
- **Web 优先**，移动端待功能稳定后实现。
- 数据使用 **MySQL 数据库**存储（后端 Spring Boot）。
- **不做**：假期/停课日设置、JSON 备份导入导出、报表打印导出。

## 3. 总体功能架构

系统分为「管理后台（录入与操作）」与「前台（查看与回顾）」两大部分，数据同源。

```
备课排课管理系统
├── 管理后台（录）
│   ├── 学生管理
│   ├── 时间段管理
│   ├── 课程管理（每生一门语文课）
│   ├── 字典管理（年级 / 顺延原因预设）
│   └── 排课系统（当月网格拖拽 + 保存关闭上月顺延 + 按学生出图）
└── 前台（看）
    ├── 今日视图（落地页）
    ├── 数据总览（按月查询 + 历史月未上课明细 + 月收入）
    ├── 当月课程表（复用网格，管状态）
    ├── 待补课清单（首页，无则不显示）
    └── 顺延分类统计
```

## 4. 功能详述

### 4.1 学生管理
字段：

| 字段 | 说明 |
|---|---|
| 姓名 | 必填 |
| 年级 | 取值自字典（小一~小六 / 初一~初三 等自由文本） |
| 电话 | 选填 |
| 家长微信 | 选填 |
| 家庭地址 | 必填（用于上门/路线参考） |
| 课程价格 | 单价（元/节），用于月收入统计 |
| 状态 | 在读 / 暂停（归档） |
| 专属颜色 | 用于课表着色区分 |
| 备注 | 选填 |

交互：
- 列表 + 搜索（按姓名/年级）。
- 详情页可查看该生所有课程与当前待补课数。
- **删除保护**：有未结课程/未来排课时禁止硬删，须先改状态为「暂停」归档。
- 颜色自动分配，可手动修改。

### 4.2 时间段管理
字段：名称（可选）、起止时间、排序、启用。

交互：
- 增删改 + 排序调整。
- **校验不能重叠**：新增/修改时段若与已有时段时间区间交叉，拦截并提示。
- 作为排课网格的「列（每列一个时段）」。
- 删除时段：若有排课引用，弹确认一并处理。

### 4.3 课程管理
模型：**课程 = 某个学生的一门语文课**（挂在学生下）。
字段：归属学生（只读）、科目（固定=语文）、价格（取自学生课程价格）、备注。

交互：
- 每个学生一条语文课配置，便于排课时直接关联价格。
- 课程可「停用」（学生不学这门了，保留历史）。

### 4.4 排课系统（核心）
布局：**左侧学生列表（可拖拽、可搜索）** + **中间当月网格（首列=日期，每行一天；首行=时间段，每列一个时段）** + 右侧学生信息。

规则：
- **拖拽建课**：把学生拖入某单元格 → 取该生课程/价格、时长=该时段 → 生成一条排课。
- **每格仅 1 人**（1 对 1，拖入已有学生时拦截冲突）。
- **只排当月**：网格仅展示并允许编辑当前月份日期。
- 单元格显示学生名 + 专属颜色；可拖出或点删。
- 网格**无课显空白**，**周末不置灰**。
- **保存逻辑**：点「保存」时，后端先查**上月所有顺延课**，有则**保存排课的同时全部关闭**（视为已安排进本月）。
- **按学生生成图片**：选学生 → 渲染其当月课表 → 导出 PNG（发家长/打印用）。
- 冲突校验：同格拖入两人时实时拦截。

### 4.5 请假 / 顺延
- 在排课或前台课程表中，选中某节课 → 标记「顺延」→ 弹窗必填：
  - **请假方**：学生请假 / 老师请假；
  - **原因**：文本（或选择字典预设）。
- 该课状态置 `顺延`，原因与请假方留存，自动进入待补课。
- 不补的情况 → 标记「作废」（仍留记录备查）。

### 4.6 补课闭环与待补课
- **待补课定义**：状态 = 顺延 且未关闭（未补/未作废）的课。
- **前台首页（落地页）实时查询**：有待补课则列表展示，**无则不显示**。
- 每项操作：「**已安排进本月课程**」→ 关闭该待补项（手动关闭，用于关更早月份遗留或不走整月保存时）。
- **跨月消除**：上月没上的课，本月（或后续月）排入课程表后，经关闭动作即不再是待补——由教师在网格拖入实际补课日期完成，再关闭。
- 补课日期可落任意月（存字段），不占新格。
- 「月末统计」以实时查询实现（随时看待补课），不强制月末跑批。

### 4.7 字典管理
维护字典表，供下拉与选项复用：
- **年级字典**：小一~小六、初一~初三 等（自由文本可增）。
- **顺延原因预设**：如 学生病假 / 老师有事 / 节假日 / 其他，供顺延弹窗快速选择。

### 4.8 数据总览（前台）
- **按月查询**：选择任意月份查看。
- **总览卡片**：本月排 N 节 ｜ 已上 X ｜ 顺延 Y（学生请假 a / 老师请假 b）｜ 已补 Z ｜ 作废 W ｜ 仍待补 K。
- **历史月未上课明细**：历史月份展示「未上课课程表格 + 原因」（顺延未补、作废的课程逐行列示）。
- **每月收入统计**：`月收入 = (正常上课节数 + 已补节数) × 该生课程价格`；顺延未补、作废不计入。
- **顺延分类统计**：区分 学生请假 vs 老师请假 各多少次。

### 4.9 今日视图（落地页）
- 展示**今天**的所有课程（学生/时段/状态）。
- 一键标记：正常上课 / 顺延（填原因）。
- 顺带提示「今日该补的待补课」。

### 4.10 当月课程表（前台）
- **复用**后台排课同款月网格（首列日期 / 首行时段）。
- 每格点开可改状态：正常上课 / 顺延（弹窗填原因）/ 已补 / 作废。
- 顺延标红并显示原因。
- 历史月只读（不可改状态，已归档）。

## 6. 课程状态机

```
        创建
         │
         ▼
      [未上] ──(到点/标记)──▶ [正常上课]
         │
         └──(标记顺延,必填 学生/老师+原因)──▶ [顺延]
                                              │
                              ┌───────────────┴───────────────┐
                              ▼                               ▼
                       [已补](约补课完成)              [作废](不补,留痕)
                              │
                              ▼
                        closed = true（待补关闭）

未来日期显示「未上」；历史月只读归档。
```

状态值：`UNTAKEN`(未上) / `NORMAL`(正常上课) / `ABSENT`(顺延) / `MADEUP`(已补) / `CANCELLED`(作废)。

## 7. 非功能需求
- 数据实时同步（Web 访问同一后端）。
- 课表着色、状态底色在打印/出图中保留（出图走前端截图）。
- 月份切换顺畅，网格渲染性能（一个月最多 31 天 × 时段数）。
- 数据安全：本地 MySQL，备份由数据库运维负责（不在应用内做 JSON 导出）。

## 10. 风险与待确认
1. **MySQL 连接信息**：库名 / 用户名 / 密码 待补充（`47.116.35.76`）；`application.yml` 先用配置占位。
2. **「已安排进本月课程」精确动作**：当前定义为「仅关闭待补项，实际补课由教师另拖网格」。若需点按钮直接在该月网格生成补课单元，需调整。
3. **跨多月待补**：上月顺延由「保存当月排课」自动关闭；更早月份遗留的待补走首页手动关闭，是否足够待验证。
4. **月收入口径**：`(正常上课 + 已补) × 学生价格`，顺延未补/作废不计——已确认。
