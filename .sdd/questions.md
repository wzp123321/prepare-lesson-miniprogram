## 设计阶段需注入的硬约束（给子智能体）

- 前端 UI 组件一律 `el-*`（Element Plus），**禁止**使用 `te-*` / `@tiansu/*`。
- 排课网格、拖拽等高度定制交互在 Element Plus 之上自绘。
- 后端 ORM = MyBatis-Plus；独立 Spring Boot，**不引**天溯 `energy-parent` 私有依赖体系。
- 5 张表：student / time_slot / course / lesson / dict；状态机见 PRD 第 6 章。
