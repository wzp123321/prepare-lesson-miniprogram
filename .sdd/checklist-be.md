- **待确认项**：Q17（MySQL 库名/账号/密码）仅 A-01 占位，不阻塞验收。

## 四、关键验收口径（硬约束固化）
1. **月收入（Q2）**：仅 `NORMAL` + `MADEUP` 计入；`ABSENT` 未补、`CANCELLED` 不计。
2. **已补 Z**：仅 `status=MADEUP` 计数；自动/手动关闭（`closed=1` 但 `status=ABSENT`）**不计入 Z**，仅消除待补显示。
3. **待补定义**：`status=ABSENT AND closed=0`。
4. **补课跨月（Q4）**：`make_up_date` 可落任意月，不占新格。
5. **技术栈**：Spring Boot + MySQL 8.0 + MyBatis-Plus；无天溯 `energy-parent` 私有依赖；DDD 分层，核心域规则在 domain/service。
